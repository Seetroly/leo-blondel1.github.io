# Portfolio · Léo Blondel

Site statique publié avec GitHub Pages : quatre pages HTML, une feuille de style commune (`style.css`) et un petit script (`script.js`).

En ligne : https://seetroly.github.io/leo-blondel1.github.io/

## Pages

- `index.html` : accueil, projet de stage, motivations et parcours
- `realisations.html` : toutes les productions, filtrables par type, suivies des études de cas
- `a-propos.html` : parcours
- `mont-blanc.html` : récit du tour du Mont-Blanc

## Fichiers

Toutes les images et vidéos sont à la racine, à côté des pages HTML.
`apercu.jpg` sert d'image d'aperçu lors d'un partage (LinkedIn, WhatsApp, etc.).
